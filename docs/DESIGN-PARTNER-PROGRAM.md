# Design Partner Program

The initial objective is NOT funding.
The initial objective is **GET REAL USAGE**.

## Target Progression

1. **10 Developers**: Initial friction testing. Local CLI and SDK usage.
2. **3 Active Teams**: Multi-agent deployment. Real world scenarios (e.g., support automation).
3. **1 Serious Design Partner**: A company routing mission-critical agent actions through HEED.
4. **Paid Pilot**: Validating willingness to pay for the commercial layer.
5. **Repeatable Product**: Scaling GTM.

## Key Metrics to Track
- Agent executions per day
- Actions evaluated
- Unique systems controlled
- Number of interventions (ASK states triggered)
- Actions BLOCKED (proving value)
- Repeat usage retention
