# Business Model Hypothesis

## Potential Adoption Layer
- `@heed/runtime`: Open-source core execution engine.
- Basic Connectors (GitHub, Slack, HTTP).
- Local runtime execution and basic SQLite/PostgreSQL persistence.
- Single-agent policy definitions (`heed.config.yaml`).

## Potential Commercial Layer
- **Team Policy Management**: Centralized synchronization of Execution Contracts.
- **Organization-wide Execution Visibility**: A managed Control Plane UI.
- **Advanced Connectors**: Enterprise systems (Salesforce, SAP, Workday, internal DBs).
- **Enterprise Deployment**: Role-based access control, SSO, and scalable event storage.
- **Centralized Evidence**: Immutable audit logs with cryptographic guarantees for compliance.

*Note: This is an unvalidated hypothesis to be refined post-customer discovery.*
