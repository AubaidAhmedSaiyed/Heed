# HEED Examples

The examples have been migrated to the `apps/demo-agent` package for integrated testing against the local `runtime-sdk`.

To view the examples, see:
- [`apps/demo-agent/src/simple-example.ts`](../apps/demo-agent/src/simple-example.ts): Demonstrates generic intent-wrapping of a real agent.
- [`apps/demo-agent/src/benchmark.ts`](../apps/demo-agent/src/benchmark.ts): Demonstrates the contextual decision accuracy compared to static RBAC.

To run them, you can use the root command:
```bash
npm run demo
```
